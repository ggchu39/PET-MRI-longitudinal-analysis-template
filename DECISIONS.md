# Decision log
## 2026-05-01 - Repository scope

Decision: This repository will use simulted data only. 
Rationale: The repository is intended as a public portfolio example demonstrating reproducible PET/MRI-style data organization, quality-control logic, longitudinal modeling, and Quarto-based reporting. It must not expose real participant data, unpublished project materials, collaborator-owned analyses, or supervisor-specific file structures.

## 2026-05-03 — Workflow focus

Decision: The first version will focus on a compact longitudinal PET/MRI and cognition workflow.

Rationale: A small, transparent workflow is preferable to a large unfinished repository. The initial version will demonstrate simulated data generation, QC checks, paired longitudinal completeness checks, mixed-effects modeling, change-score sensitivity analysis, and report-ready outputs.

## 2026-05-03 — Variable naming

Decision: Generic variable names will be used.
 
Rationale: It reduces the risk of revealing unpublished project structures while still demonstrating relevant analytical skills.
