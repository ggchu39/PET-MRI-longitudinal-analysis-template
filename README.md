# PET/MRI Longitudinal Analysis Template

This repository provides a reproducible R/Quarto template for analysing simulated longitudinal PET/MRI and cognitive data.

It demonstrates:

- simulated PET/MRI-style data organisation;
- neuroimaging-style quality-control checks;
- paired longitudinal completeness checks;
- descriptive summaries and figures;
- mixed-effects longitudinal modelling;
- within-person and between-person PET marker decomposition;
- change-score sensitivity analysis;
- Quarto-based reporting.

This repository is intended as a public portfolio example. It does not contain real participant data, clinical data, raw neuroimaging files, unpublished project materials, supervisor-specific files, or collaborator-owned results.

## Repository scope

All data in this repository are simulated.

The workflow is inspired by common analytical tasks in cognitive neuroscience and PET/MRI research, including the analysis of molecular imaging markers, structural MRI-derived measures, and cognitive performance across repeated assessments.

The repository focuses on the downstream statistical workflow after imaging-derived measures have been extracted and quality checked.

It does not perform raw neuroimaging preprocessing.

## How to run the workflow

From the repository root, run:

```r
source("R/00_run_all.R")
```

This will:

1. simulate the dataset;
2. run quality-control checks;
3. create descriptive summaries and figures;
4. fit longitudinal mixed-effects models;
5. run change-score sensitivity models;
6. export tables and figures to the `outputs/` folder.

## Quarto report

After running the R workflow, render the Quarto report with:

```bash
quarto render reports/pet_mri_longitudinal_analysis_template.qmd
```

The report summarises the simulated dataset, QC decisions, descriptive outputs, longitudinal models, change-score sensitivity analyses, and limitations.

## Main workflow scripts

| Script | Purpose |
|---|---|
| `R/00_run_all.R` | Runs the full workflow in order |
| `R/01_simulate_data.R` | Simulates longitudinal PET/MRI/cognition data |
| `R/02_qc_checks.R` | Applies QC checks and paired completeness checks |
| `R/03_descriptives.R` | Produces descriptive tables and figures |
| `R/04_longitudinal_models.R` | Fits mixed-effects longitudinal models |
| `R/05_change_score_models.R` | Runs change-score sensitivity models |

## Data protection

This repository uses simulated data only.

It does not include:

- real participant-level data;
- clinical data;
- raw PET or MRI files;
- NIfTI files;
- private project outputs;
- unpublished collaborator materials;
- supervisor-specific file structures;
- protected screenshots or reports.

The variable names and values are generic and are used only to demonstrate reproducible workflow structure, quality-control logic, and statistical modelling principles.

## What this template demonstrates

This repository demonstrates skills relevant to PET/MRI and cognitive neuroscience research:

- organising longitudinal imaging-derived data;
- documenting QC exclusions;
- checking paired repeated-measures completeness;
- modelling brain–behaviour associations;
- separating within-person and between-person effects;
- performing change-score sensitivity analyses;
- producing transparent reports with R and Quarto.

## Limitations

This template is intentionally simplified.

It does not include:

- PET kinetic modelling;
- PET partial-volume correction;
- MRI segmentation;
- image registration;
- BIDS validation;
- scanner harmonisation;
- FreeSurfer, FSL, AFNI, or SPM preprocessing scripts.

Instead, it focuses on the downstream statistical analysis workflow using simulated imaging-derived variables.
