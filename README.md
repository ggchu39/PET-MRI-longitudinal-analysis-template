# PET/MRI Longitudinal Analysis Template

This repository provides a reproducible R/Quarto template for analysing simulated longitudinal PET/MRI and cognitive data. It demonstrates project organization, simulated data generation, neuroimaging-style quality control, paired longitudinal completeness checks, regression-based brain–behaviour modeling, and transparent reporting.

The repository is intended as a public portfolio example. It does not contain real participant data, unpublished project materials, raw neuroimaging files, supervisor-specific files, or collaborator-owned results.

The workflow is inspired by common research questions in cognitive neuroscience and neuroimaging, including how molecular PET markers, structural MRI-derived measures, and cognitive performance may be analyzed across repeated assessments.

## Data protection and scope

All data in this repository are simulated. No real participant-level data, clinical data, raw imaging files, private analysis outputs, or unpublished collaborator materials are included.

The variable names and values are generic and are used only to demonstrate reproducible workflow structure, quality-control logic, and statistical modeling principles.
